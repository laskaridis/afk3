## Project discovery
- Node 22 / npm 10; deps (commander, vitest, typescript, @types/node) are already in node_modules and the registry is reachable.
- Tests: `npm test` builds first (integration tests run the built `dist/cli.js`) then runs vitest. `npm run typecheck` covers src and test.
- Integration tests use `test/helpers.ts` (`createFakeCodexEnvironment(steps)`, `startAfk`) with the scripted fake `test/fixtures/fake-codex.mjs` placed first on PATH; `fake.soleInvocation()` returns argv/cwd/stdin/outputPath.
- The build script chmods `dist/cli.js` to 755 (tsc does not); without it npm's bin link is non-executable and a globally installed `afk` shadows it.
- A different global `afk` (afk-cli-core, from ../afk2) exists on this machine's PATH; do not rely on bare `afk`.
- Module layout follows specs/afk-cli-core.design.md: src/cli.ts, src/protocol.ts, src/session.ts, src/runner.ts (runAfk with injected SessionRunner), src/reporter.ts (exitCodeFor, formatFinalStatus); prompt still to come.
- fake codex supports per-invocation scripts: createFakeCodexEnvironment({ sessions: [steps, ...] }) (last list repeats).

## 2026-10-27 TASK-003
- Task id: TASK-003
- What was implemented:
  - src/runner.ts: `runAfk(config, sessionRunner, reporter)` runs fresh sessions up to maxIterations (default 10): repeat -> next, fail -> surface summary + next, complete -> success, blocked -> stop with blocker_text, budget exhausted -> iteration-limit(limit). Decides only from session results.
  - Execution errors (launch failure, non-zero exit, missing/invalid response) stop the run immediately as `execution-error`; retry policy is deliberately left to TASK-004.
  - src/reporter.ts: EXIT_CODES, exitCodeFor, formatFinalStatus (codes 0/1/2/3/4 per design table; 5/130 come with later tasks).
  - cli.ts: `--max-iterations <count>` (positive integer only, else commander option error -> exit 2, no launch), wired to runAfk with iteration banners and failure summaries on stderr.
  - Fake codex + helpers extended with per-invocation `sessions` scripts.
- Files changed:
  - src/runner.ts, src/reporter.ts, src/cli.ts, test/runner.test.ts, test/run-loop.test.ts, test/fixtures/fake-codex.mjs, test/helpers.ts, specs/afk-cli-core.plan.json (status), progress.txt
