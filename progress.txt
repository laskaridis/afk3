## Project discovery
- Tests run the built CLI (`pnpm test` builds first, then vitest); fake agent executables live in test/fixtures and are put first on PATH by test/helpers.ts.
- No python in this environment (asdf shim fails); use node for scripted edits.
- The fake codex `finalMessage` step writes to stdout (+ newline). Any extra `stdout` step makes Codex's final message invalid, since Codex stdout is the final message.
- Agent prompt is delivered on stdin; fake records it as `stdin` in each invocation record.
- Run `pnpm check` (typecheck, lint, prettier) as well as `pnpm test` before committing.
