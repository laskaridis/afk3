## Project discovery
- Node 22 / npm 10; deps (commander, vitest, typescript, @types/node) are already in node_modules and the registry is reachable.
- Tests: `npm test` builds first (integration tests run the built `dist/cli.js`) then runs vitest. `npm run typecheck` covers src and test.
- Integration tests use `test/helpers.ts` (`createFakeCodexEnvironment(steps)`, `startAfk`) with the scripted fake `test/fixtures/fake-codex.mjs` placed first on PATH; `fake.soleInvocation()` returns argv/cwd/stdin/outputPath.
- The build script chmods `dist/cli.js` to 755 (tsc does not); without it npm's bin link is non-executable and a globally installed `afk` shadows it.
- A different global `afk` (afk-cli-core, from ../afk2) exists on this machine's PATH; do not rely on bare `afk`.
- Module layout follows specs/afk-cli-core.design.md: src/cli.ts, src/protocol.ts, src/session.ts, src/runner.ts (runAfk with injected SessionRunner), src/reporter.ts (exitCodeFor, formatFinalStatus); prompt still to come.
- fake codex supports per-invocation scripts: createFakeCodexEnvironment({ sessions: [steps, ...] }) (last list repeats).

## 2026-10-27 TASK-005
- Task id: TASK-005
- What was implemented:
  - session.ts: `runSession` accepts `signal` (AbortSignal) and `graceMs`. On abort it forwards SIGINT to the child, escalates to SIGTERM after graceMs and SIGKILL after 2*graceMs, and resolves `{kind:"interrupted"}` only after the child's `close`. An already-aborted signal returns `interrupted` without launching. Child is never detached.
  - runner.ts: `interrupted` session result -> `{kind:"interrupted"}` immediately (no retry, no further iteration).
  - reporter.ts: exit code 130, status "interrupted by user".
  - cli.ts: SIGINT handler aborts an AbortController (repeat SIGINTs are no-ops); `AFK_TERMINATION_GRACE_MS` env (undocumented test knob) overrides the 5s default grace.
